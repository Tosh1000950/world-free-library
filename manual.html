1. このサイトでできること（3ステップの使い方）

本サイトは、世界各国の国立図書館・デジタルアーカイブ（全40区分・サービス）について、「日本在住・現地図書館カードなし」の視点からアクセス実態を調べた実務ガイドです。単にリンクを並べるだけでなく、以下の3ステップで「目的に合い、実際に本文まで読める図書館」を探せます。

STEP 1

読める館を絞り込む

まずは一覧上部の「登録なしで全文が読めるものだけ表示」トグルや、地域・時代・資料種別（書籍・新聞・写本・古地図・学術・ウェブ）で対象を絞ります。

STEP 2

4軸とバッジで実態を読む

各カードのR（登録）・J（日本閲覧）・D（保存）・T（型）とバッジを見て、「登録不要か」「リンク先依存か」「一部復旧中か」を事前に確認します。

STEP 3

現地検索ランチャーで飛ぶ

調べたい語句（海外館は英語・現地語推奨）をランチャーに入れると、URL仕様が確定済みの23アーカイブの検索結果へ1クリックで直接飛べます。

2. 4軸ラベル（R / J / D / T）の読み方

デジタル図書館は「検索は無料だが本文は現地カード限定」「閲覧はできるが一括保存は不可」のように条件が複雑です。星や総合点では誤解を生むため、本サイトでは性質の異なる4つの独立した軸で表示しています。

  • 登録 R（Registration）： 利用開始に必要なハードル（R0 不要 → R1 メールのみ → R2 本人確認・審査 → R3 居住・資格要件 → R4 館内・提携館端末のみ）。
  • 日本から閲覧 J（Japan Access）： 日本のIP・環境から本文が読めるか（J3 PD全文が広く可 → J2 PDのみ・年代等制限 → J1 検索・プレビュー中心 → J0 原則不可 ／ J- リンク先依存）。
  • 保存 D（Download）： PDF等で持ち帰れるか（D3 一括DL可 → D2 1ページ単位・透かし印刷・DRM貸出など条件付き → D1 閲覧のみ ／ D- リンク先依存）。
  • 型 T（Architecture Type）： 図書館自身がデータを保有しているか（直接）／ 直接と集約が混在（混合）／ 所蔵機関へのリンクを集約する検索窓口か（ポータル）。
色分けの目安（4色マス） 緑色＝登録不要や一括DL可など制限が緩い ／ 黄土色＝年代制限・ページ単位保存など条件付き ／ 赤色＝館内限定・本人確認審査・検索のみ等 ／ 青色＝ポータル型（所蔵元ごとに異なるため J-・D- と表示）。

3. 「登録なしで全文が読めるものだけ表示」トグルの意味

検索パネル最上部の緑枠チェックボックスをONにすると、「R0（登録不要）」「直接保有または混合保有」「日本からパブリックドメイン（PD）等の本文が広く閲覧可能」の条件を満たすアーカイブだけを抽出します（2026年11月調査時点で全40件中 27件）。

トグルをONにすると除外されるもの（13件）

  • ポータル型（7件）： Europeana、DDB、DPLA、NDLI、DigitalNZ、CORE / DOAJ / DOAB、BDPI。原ファイルを自分で持たず、リンク先の機関ごとに可否や登録条件が異なるため除外されます。
  • 要本人確認・要館内端末・提携館PC（3件）： NDL（個人送信限定＝R2・国内居住＆本人確認審査）、NDL（館内限定＝R4）、韓国国立中央図書館 NLK（著作権あり資料は提携館の指定PC＝R4）。
  • 復旧途上・日本からの無登録到達が限定的（3件）： British Library（サイバー攻撃後の段階復旧途上）、中国国家図書館 NLC（多くの全文データベースは登録・実名区分に依存）、ロシア NEB（日本からの到達性・実態の個別確認が未了かつ要注意扱い）。
ON時にも残る資料に関する注意 このトグルをONにした場合でも、年代制限付き・一部条件付きのアーカイブ（例：HathiTrust の米国刊行95年超前／米国外125年超前ルールや、Delpher の年代区分など）や、R0＋PD相当と整理されている一部の「追加検証中」アーカイブは表示対象に含まれます。最終的な閲覧・保存条件は各カードの「注意点・実態」欄をご確認ください。

4. 現地アーカイブ横断検索ランチャーの使い方と注意点

まず区別したい「A欄」と「B欄」

  • A. この一覧をキーワードで絞り込む（左側）： 本ガイド内の40枚の図書館カードから、「フランス」「新聞」「写本」「IIIF」などの言葉で該当する図書館を選び出す欄です。
  • B. 現地アーカイブ横断検索ランチャー（右側）： あなたが本当に調べたい書名・著者名・人名・地名を入力し、各アーカイブのサイトへ直接検索クエリを飛ばす欄です。

ランチャーの基本操作

  1. B欄に検索語を入力します（下のサンプルチップをクリックしても入力できます）。
  2. URLパターンが公式仕様・動作確認で確定している 23アーカイブ のカード下部に、緑色の「『○○』で現地検索 ↗」ボタンが現れます（ページ上部の「対応アーカイブの検索リンク一覧を開く」ボタンを押すと、対応館だけをまとめたリンク集も開けます）。
  3. 気になる館のボタンをクリックすると、新しいタブでその図書館の検索結果ページが開きます（ブラウザのポップアップブロックを防ぐため、23館を同時に一括オープンせず1件ずつ開く設計です）。

※ SPA動的画面・認証・書架記号依存などで安定した直接検索URLを持たない17アーカイブ（DigiVatLib、ÖNB Digital、青空文庫、BNE Digital、NDLI、韓国NLK、中国NLC等）には推測で検索URLを作らず、「公式サイト ↗」からの案内にとどめています。

最重要の注意点：日本語キーワードは海外アーカイブで「0件」になりやすい 日本の図書館（NDLや青空文庫、日本語版Wikisource）とは異なり、海外の図書館目録（タイトル・著者名・件名・OCR全文）は現地語や英語で登録されています。
そのため、日本に関する歴史資料・地図・写真・報道を探す場合でも、「日本」「明治」「東京」「長崎」といった日本語のまま入力すると、海外アーカイブ側では検索結果が0件になることがよくあります。

おすすめの言語選びとキーワード例

調べたいアーカイブの言語圏や国際共通語（英語）に言い換えて検索するのが基本です。英語・ローマ字をベースにしつつ、フランス語圏（Gallica）などでは現地語綴りも試すとヒット率が大きく上がります。

5. IIIF対応 バッジの意味と Phase 2 計画

IIIF（International Image Interoperability Framework）とは、世界中の図書館や博物館が保有する高精細な写本・古地図・書籍画像を、共通の形式で配信・拡大・比較できるようにする国際規格です。

  • v1（現在）の扱い： IIIFに対応し、公式仕様が確認できた 14サービス に IIIF対応 バッジを付け、カード内の青い枠（IIIF案内）でマニフェストURLの形式や公式ドキュメントへのリンクを案内しています。
  • v1では案内表示のみ： 現在のバージョンではサイト内にIIIFビューアは組み込んでいません（また、外部の汎用IIIFビューアサイトへの直接リンクも、保守性・外部依存回避のため設置していません）。
  • Phase 2 予定： 複数の図書館の写本や地図を同じ画面で並べて拡大比較できるサイト内IIIFビューア（Mirador / Universal Viewer 等を用いた軽量な別ページ構成など）は、今後の Phase 2 計画として案内しています。

6. 追加検証中 バッジの意味とデータ調査日

本サイトに掲載している全40件の評価・4軸ラベル・規模表記・AI要約訂正は、2026年11月調査（2026年11月18日時点の公式サイト・公式ヘルプのウェブ索引確認）に基づいています。各カードの規模欄では、出典元の発表年次が異なるため「2025年1月時点」「2024年9月時点」「2026年11月調査時点」のように時点を明記しています。

そのうち、公式サイトの枠組みや存在は確認できているものの、日本IPからの実ブラウザでの個別クリック検証（どこまで一括DLできるか、個別の検索URLパラメータや例外挙動の細部）がまだ完了していない 8サービス には 追加検証中 バッジを付けています。

  • 該当する8件：ポルトガル BNDigital、イタリア Internet Culturale、デンマーク王立図書館、チェコ Kramerius、ロシア NEB（要注意 併記）、メキシコ BNDM、アルゼンチン BNMM、イベロアメリカ BDPI。

7. 日本の国立国会図書館（NDL）が3区分に分かれている理由

世の中の解説やAI要約では「国立国会図書館デジタルコレクションは無料で読める」「あるいは登録しないと読めない」と一括りに書かれがちですが、実際には所蔵資料1点ごとに公開レベルがまったく異なるため、1枚のカードにまとめることができません。

本サイトでは利用者が誤解しないよう、NDL公式の区分に合わせて次の 3つの独立カード に分けて収録しています：

  1. インターネット公開（R0 / J3 / D3 / 直接）： 世界中から誰でも・ログインなしで全文画像やPDFを利用できる区分。
  2. 図書館・個人送信限定（R2 / J3(国内限定) / D2 / 直接）： 日本国内居住者の本登録（本人確認書類の審査あり）または承認図書館の端末向け。印刷用PDFには氏名・ID等の透かしが入り、海外在住者は対象外です。また出版社等の再調査により館内限定へ戻る場合があります。
  3. 国立国会図書館内限定（R4 / J0 / D2 / 直接）： 東京本館・関西館・国際子ども図書館へ来館して館内端末を使う必要があります。

8. よくある疑問（Q&A）

Q. 現地検索ランチャーで検索したのに、海外の図書館で結果が0件になります

入力欄に日本語（例：「明治」「東京」「夏目漱石」）が入っていませんか？海外の図書館目録は英語や現地語で登録されていることが多いため、Meiji / Tokyo / Japan / Japon / Nagasaki のような英語・現地語・ローマ字に切り替えて再検索してみてください。

Q. 「R0（登録不要）」なのに本文が読めない本があるのはなぜですか？

「R0」はアカウント作成が不要という意味であり、収録されている全資料がパブリックドメイン（PD）という意味ではありません。同じアーカイブ内でも、著作権が切れた古い資料は全文閲覧でき、比較的新しい資料は書誌検索やスニペット表示のみになることがあります（軸 J やカードの「注意点・実態」欄をご確認ください）。

Q. ポータル型（Europeana / DPLA 等）が「リンク先依存（J- / D-）」になるのはなぜですか？

ポータル型は数百〜数千の図書館・博物館の目録をまとめて検索できる便利な窓口ですが、画像やPDFのファイル自体はリンク先の所蔵機関が持っています。そのため、リンク先によっては「登録不要で一括DL可」な資料もあれば、「閲覧のみ」「館内限定」の資料も混ざっており、サイト全体を一律の数値で評価できないためです。

Q. 「現地検索」ボタンが出ないアーカイブがあるのはなぜですか？

SPA（クライアントサイド動的遷移）や書架記号・認証等により、確実な検索結果URLパターンが固定されていない17のアーカイブについては、推測でリンク切れURLを作らない方針としているためです。これらの館はカード内の「公式サイト ↗」から現地トップの検索欄をご利用ください。
